# 📚 Marvellous Study Tracker App

### (Java | CUI + GUI)

## 📌 Description

The **Marvellous Study Tracker App** is a Java-based application designed to help users **track, manage, and analyze their study sessions** efficiently.

The application provides both:

* 🖥️ **CUI (Console User Interface)** – simple and lightweight interaction
* 🪟 **GUI (Graphical User Interface)** – user-friendly visual interface

It enables users to log study activities, monitor progress, and generate summaries for better productivity.

---

## 🚀 Features

* 📝 Log study sessions (subject, duration, date)
* 📊 View study history
* 📈 Generate summaries and reports
* 📅 Track study progress over time
* 📂 Export data (CSV or file-based storage)
* 🖥️ Dual interface:

  * CUI (Terminal-based)
  * GUI (Swing/AWT based)

## ⚙️ How It Works

### 🔹 Logging Study Sessions

* User enters:

  * Subject
  * Duration
  * Date
* Data is stored in a file (CSV or text format)

---

### 🔹 Viewing Logs

* Displays all study sessions
* Allows filtering by:

  * Date
  * Subject

---

### 🔹 Generating Reports

* Calculates:

  * Total study time
  * Subject-wise breakdown
* Helps analyze study habits

---

## 🧑‍💻 How to Run

### 🔧 Compile (CUI)

```bash
javac StudyTracker.java
```

### ▶️ Run (CUI)

```bash

```

---

### 🪟 Run GUI Version

```bash
javac StudyTrackerGUI.java
```
